# Filter

## Description 

A C program to apply different filters to BMPs: grayscale, reflect, edges, blur and sepia.
This project was completed as part of CS50's Introduction to Computer Science.

## Built with

C programming language

## Usage 
```bash
./filter -g infile.bmp outfile.bmp
./filter -r infile.bmp outfile.bmp
./filter -e infile.bmp outfile.bmp
./filter -b infile.bmp outfile.bmp
./filter -s infile.bmp outfile.bmp
```
